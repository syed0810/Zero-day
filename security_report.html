Project Zero-Day is an autonomous, evidence-driven multi-scanner security analysis pipeline targeting local web applications (such as OWASP Juice Shop and local services). It unifies containerized vulnerability scanners with machine learning prioritization, local scenario retrieval-augmented generation (RAG), local LLM security advisories, and an authoritative Policy Gate with strict evidence verification invariants.

Stage 0
Docker Scanner Suite
Automated, non-destructive scans via official OWASP ZAP and ProjectDiscovery Nuclei container images.
Stage 1
Ingestion & Dedup
Normalizes heterogeneous findings into the canonical schema and deduplicates overlapping multi-scanner detections.
Stage 2
Decision Prioritization
Classifies vulnerabilities into P1–P4 severity tiers using a trained ML Decision Policy Model and deterministic action heuristics.
Stage 3
Contextual RAG & Gemma AI
Sub-millisecond FTS5 scenario retrieval from scenarios.db enriched with local Ollama Gemma vulnerability explanations and remediation advice.
Stage 4 & 4b
Policy Gate & Loop
Authoritative scope enforcement (loopback & port isolation). Bounded autonomous investigation loop under strict request budgets.
Stage 5 & 6
Verification & Dashboard
Defensive invariant: scanner alerts are never auto-verified (verified: false). Rendered into an interactive 100% offline HTML dashboard.
